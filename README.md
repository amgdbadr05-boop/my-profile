# Amgad Badr — Personal Portfolio

## Requirements
- Node.js (LTS recommended)
- VS Code

## Run locally
1. Extract this folder and open it in VS Code.
2. Open the VS Code terminal in this folder.
3. Run `npm install`.
4. Run `npm start`.
5. Open http://localhost:3000 in your browser.

For automatic restart while developing, run `npm run dev`.

## Add your profile photo
Copy your photo into `public/images/` and name it exactly `profile.jpg`.
Use a clear, square-ish JPG or PNG (if PNG, update the image path in `views/index.html`).
The page currently shows an "AB" fallback until you add the photo.

## Customize
- Main page: `views/index.html`
- Styles and animations: `public/css/style.css`
- Arabic/English translations and theme behavior: `public/js/script.js`

The theme and language choices are saved in the browser using localStorage.
